# 飞书多维表格 · 仪表盘滚动表格组件

这是一个用于 **飞书多维表格仪表盘** 的自定义组件，解决官方仪表盘表格组件无法滚动与支持添加数据容易误碰、美观性的问题，适合大屏、看板、实时数据展示场景。

## ✨ 功能简介

- 📊 **自动滚动展示**  
  表格内容在可视区域内，自动按行或页向上滚动，无需手动滚动或翻页。

- 🔁 **多种滚动模式**
  - 按行滚动
  - 分页滚动

- 🎛 **可视化配置**
  - 选择要展示的数据表与视图
  - 设置显示字段
  - 调整滚动速度

- 🎨 **样式适配**
  - 支持自定义行高亮显示
  - 自动跟随飞书浅色 / 深色模式
  - 支持溢出文本滚动
  - 支持斑马纹

---

## 📦 使用方式

### 1️⃣ 安装组件

1. 下载本项目最新 Release 中的构建包  
2. 在飞书开发者后台创建一个 **多维表格仪表盘插件**
3. 上传构建后的代码包
4. 提交审核并发布到企业内部应用中心

### 2️⃣ 在仪表盘中使用

1. 打开任意一个 **多维表格**
2. 进入 **仪表盘**
3. 点击「添加组件」→「插件」
4. 选择「滚动表格组件」
5. 在右侧配置面板中：
   - 选择数据表和视图
   - 添加需要展示的字段
   - 调整滚动行为即可生效

---

## ⚙️ 配置说明

| 配置项 | 说明 |
|------|------|
| 数据视图 | 选择多维表格中的某个视图 |
| 显示字段 | 添加需要在表格中展示的字段 |
| 滚动模式 | 按行滚动 / 分页滚动 |
| 滚动速度 | 滚动的速度，间隔时长 |
| 高亮显示 | 自定义的行高亮显示 |
| 溢出文本 | 溢出文本滚动 |
